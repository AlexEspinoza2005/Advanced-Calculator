## 📋 Description

**Advanced C# Calculator** is a desktop computation tool developed with **C# and Windows Forms**. It goes beyond standard arithmetic to deliver complex mathematical functions, radix conversions, memory persistence, and an adaptable user interface with seamless theme toggling.

---

## ✨ Main Features

- 🌓 **Dynamic Light & Dark Mode:** Fluidly switch between visual themes for optimal readability in any lighting condition.
- ➕ **Core Arithmetic Operations:** High-precision addition, subtraction, multiplication, and division with negative and floating-point support.
- 📐 **Scientific & Trigonometric Suite:** Sine, cosine, tangent, logarithms, exponentiation, square roots, and degree/radian toggling.
- 🔢 **Number Base Conversion:** Instant, bi-directional conversions between **Binary, Octal, Decimal, and Hexadecimal**.
- 💾 **Memory Management:** Dedicated save, recall, and clear registers for chaining complex multi-step computations.
- 🛡️ **Mathematical Error Handling:** Built-in safeguards against division by zero, invalid root domains, and boundary operations.

## 🛠️ Solutions & Engineering Details

1. **Exponentiation Edge Cases:** Correctly handles powers of 0 ($x^0 = 1$) without throwing exceptions or generating undefined states.
2. **Division by Zero Protection:** Intercepts zero-divisor edge cases, displaying user-friendly diagnostic notices without application crashing.
3. **Negative Number Handling:** Full algebraic support for unary minus across all operational pipelines.
4. **Floating-Point & Integer Precision:** Prevents decimal truncation and maintains arithmetic fidelity across data types.
5. **Trigonometric Domain Switching:** Dynamic conversion between Radians and Degrees ensuring accurate trigonometric calculations.
6. **Radix Arithmetic:** Real-time conversion algorithms translating integer values into Binary, Octal, and Hexadecimal formats without data loss.

## 🚀 Installation and Usage

### Prerequisites
- Windows OS (Windows 10 / 11)
- [.NET Framework 4.8+](https://dotnet.microsoft.com/)
- Visual Studio (Community or Professional)

### 1. Clone the repository
```bash
git clone https://github.com/AlexEspinoza2005/Advanced-Calculator.git
cd Advanced-Calculator
```

### 2. Open & Build
1. Open `Calculadora_Grande.sln` in **Visual Studio**.
2. Select **Release** or **Debug** configuration.
3. Press `F5` or click **Start** to build and launch the application.
